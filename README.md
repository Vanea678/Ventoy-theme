# Ventoy ROG Custom GRUB Theme

Кастомна мінімалістична тема для **Ventoy**, виконана в контрастних бірюзово-червоних (`#74d6cf` / `#fb3048`) тонах із кастомними шрифтами та гладким UI. 

Тема повністю готова до встановлення та оптимізована під стандартне розширення екрана.

## Структура репозиторію

* `theme.txt` — основний конфігураційний файл інтерфейсу (координати, кольори, логіка).
* `preview.png` — фонове зображение (використовується як `desktop-image`).
* `*.pf2` — набір оптимізованих шрифтів (включаючи `DroidLogo` та `DejaVu Sans`).
* `highlight_*.png` — елементи графічного інтерфейсу для плавного підсвічування обраного пункту меню.
* `boot_menu2_c.png` — центральний спрайт для контейнера меню.

## Інструкція зі встановлення

Щоб накатнуту цю тему на свою флешку з Ventoy, виконай кілька простих кроків:

### Крок 1. Копіювання файлів
1. Створи в корені своєї Ventoy-флешки папку `ventoy` (якщо її ще немає).
2. Всередині неї створи підпапку `themes`.
3. Склонуй цей репозиторій або просто закинь папку з темою сюди.
   Шлях має виглядати так:
   ```text
   <Флешка>/ventoy/themes/ventoy-cyan-red-theme/
